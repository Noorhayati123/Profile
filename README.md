# OOP Lab 01 - Student Profile

## 1. รายละเอียดโปรเจกต์
โปรเจกต์นี้เป็นส่วนหนึ่งของใบงานปฏิบัติการที่ 1 เรื่อง การติดตั้งสภาพแวดล้อมและโปรแกรมแรกด้วย TypeScript

มีวัตถุประสงค์เพื่อเรียนรู้การเขียนโปรแกรมด้วย TypeScript และ JavaScript รวมถึงการใช้งาน Node.js และ GitHub

## 2. เครื่องมือที่ใช้
- Visual Studio Code
- Node.js
- TypeScript
- JavaScript
- Git
- GitHub

## 3. โครงสร้างไฟล์

```text
oop-lab-01/
│
├── profile.ts
├── profile.js
└── README.md
```

## 4. รายละเอียดไฟล์
- `profile.ts` : ไฟล์โปรแกรมภาษา TypeScript สำหรับสร้างข้อมูลโปรไฟล์นักศึกษา
- `profile.js` : ไฟล์โปรแกรมภาษา JavaScript
- `README.md` : ไฟล์อธิบายรายละเอียดของโปรเจกต์

## 5. วิธีตรวจสอบ Node.js

เปิด Terminal แล้วพิมพ์คำสั่ง

```bash
node -v
```

## 6. วิธีรันโปรแกรม TypeScript

```bash
npx tsx profile.ts
```

## 7. การบันทึกโปรเจกต์ด้วย Git

```bash
git init
git add .
git commit -m "Initial Lab 01"
```

## 8. สรุป
โปรเจกต์นี้ช่วยฝึกพื้นฐานการเขียนโปรแกรม TypeScript และ JavaScript การใช้งาน Node.js รวมถึงการจัดเก็บและจัดการไฟล์โปรแกรมด้วย Git และ GitHub
